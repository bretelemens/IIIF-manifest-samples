# 7.	Beeld met ge-OCR’de tekst van de hele pagina als webannotation
## use case
•	Vindbaarheid van de tekst uit uit een beeld als presentatie naast het beeld (txt)
## implementation notes
Annotation met de volledige ge-OCR’de tekst op het beeld ingebed 
*	annotations/annotation page/annotation/body
*	motivation=supplementing
*	type= TextualBody
* target: uri naar het canvas
