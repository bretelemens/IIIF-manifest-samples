# Collection
## use case
Toegang tot alle beelden uit een bepaalde collectie, m.n.:
* lijst met alle manifesten voor collectiestukken uit een specifieke bewaarinstelling
* lijst met alle manifesten voor collectiestukken voor een specifieke query in DAMS
## implementation notes
* collecties van meer dan 250 collectiestukken worden opgedeeld in subcollecties.
## samples
* 001-manifest-set/rubenshuis/collection.json: Collectie met alle manifests voor collectiestukken beheerd door Rubenshuis (Universal Viewer, Clover, Glycerine Viewer, [Mirador](), IIIF Curation Viewer)
* 001-manifest-set/rubenshuis/paged-collection.json: Collectie met alle manifests voor collectiestukken beheerd door Rubenshuis (Universal Viewer, Clover, Glycerine Viewer, [Mirador](https://projectmirador.org/embed/?iiif-content=https://bretelemens.github.io/IIIF-manifest-samples/001-set/rubenshuis/paged-collection.json), IIIF Curation Viewer)
