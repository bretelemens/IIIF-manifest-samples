# 2. Een manifest met een set reproducties
## samples
* momu silhouetten
* rubenshuis werk en voorstudies uit verschillende musea

## use case
Toegang tot een specifieke set beelden met dezelfde eigenschappen.
## implementation notes
* beelden worden handmatig geselecteerd met behulp van een manifest maker.
* er is geen paging mechanisme om grote reeksen beelden op te delen in verschillende manifests. Ook top-level en submanifests zijn niet toegelaten.
